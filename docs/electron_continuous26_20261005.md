# 电子26组成连续模型：实施进度

后续出生份额、硬率和条件终态接口的进展见[新报告](electron_response26_20261005.md)。下面保留本阶段的组件证据。

本轮增加了可执行的FP32标量查询和解析出生抽样原型。**尚未替换默认电子包；当前生产电子路径仍有83个密度节点。** 本报告不表示全包缩减、GPU吞吐或剂量验收已经完成。

## 26组成标量模型

`scripts/build_electron_scalar26.py`生成每组成一份连续密度系数，目录只有25个Schneider组成和Water_75eV；不保存83节点目录，不在主机展开节点。包括质量弹性平均自由程、受限阻止本领、质量射程、electron/photon cutoff、Urban常数和光子质量反应率。

标量由现有83节点插值响应拟合，因此中间密度比较的参考是既有插值，不是独立Geant4提取。正量采用log值的Chebyshev系数；截断阈值的拐点使用隐式等间隔log密度分段，不是重新包装83份材料响应。各组成的射程在4097个密度检查点上保持严格单调。Photon质量率同组成内最大相对差1.12e-15；Urban常数逐字节一致。

最终原型`out/electron_continuous26_20261005/scalar_v3/scalar26.npz`为1,757,398字节；解包数组2,071,904字节。不是完整包或实际GPU加载量。标量最高24阶，cutoff最高12阶；仅section0/1需要16/8个cutoff分段。没有性能实测；不可把存储缩减当成吞吐收益。

`include/carbon/electron_continuous_scalar.hpp`提供FP32查询；`scripts/check_electron_scalar26.py`编译独立C++检查，在26,624个随机密度/能量点与原生节点插值比较：

| 字段 | 最大相对差 |
|---|---:|
| 弹性反应率 | 0.057146% |
| 受限阻止本领 | 0.204123% |
| 射程 | 0.191298% |
| electron cutoff | 0.227352% |
| photon cutoff | 0.034497% |

无效密度/能量拒绝检查通过。以上是主机运行的FP32组件检查，不是GPU剂量验收。硬过程率、空碰撞majorant及终态分布均不在这个原型中。

## 解析δ电子出生

新增`include/carbon/electron_analytic_birth.hpp`：对proton/C12使用能量加权Born自由电子谱。先提出log-uniform转移能量，再按相对论修正拒绝采样；角度由同一次转移能量和母离子运动学计算，保持能量—角度相关性。Proton保留spin-half项，C12使用spin-zero项。全部抽样算术FP32；没有替换横向电子传播或界面处理。

实现检查`scripts/check_electron_analytic_birth.py`对24组条件抽样4,800,000次，与独立双精度积分比较，两种均值最大偏差2.358个抽样标准误，无无效结果。此检查只证明代码抽中了所定义的谱。当前显式支持母离子>=50MeV/u；未提供出生能量份额，也未接入生产队列。

`scripts/probe_electron_birth_analytic26.py`首先检查原83节点出生包。低统计参考中的均值最大差proton18.01%、carbon11.52%，不能直接解释为物理模型误差。进一步原生提取结果：

- Water_75eV proton2048历史：能量均值差中位0.4495%，最大1.5414%；仅分布检查，不是水剂量验收。
- Schneider section1高密度端、section7软组织和section24，各粒子4096历史，已完成6项原生提取并通过提取能量审计。
- 每种粒子的section1最低密度提取在约157秒后主动停止；尚未完成，没有出生银行/验收manifest。这两项不计入验证。

完成的三种条件在母能量>=50MeV/u的结果：

| 量 | Proton | Carbon |
|---|---:|---:|
| 能量均值相对差，中位 | 0.276193% | 0.130424% |
| 能量均值相对差，最大 | 1.418197% | 0.578594% |
| 联合CDF最大差 | 2.845470个百分点 | 5.345134个百分点 |
| 能量均值差最大标准误数 | 3.347 | 16.589 |

不确定度按独立primary历史聚类计算，未把加权电子当成独立样本。Carbon的高密度、较低母能量段存在统计上明确的差异，不能全部归因于蒙卡噪声。比较仍包含5MeV母能量箱的平均假设和原生step前母能量与实际硬事件能量的区别；原生出生记录最大离子步长0.25mm，不是当前minibeam预设0.1mm。这些可能来源尚未归因。当前数据不支持直接把解析谱作为验收完成的默认出生包。

## 剩余工作与运行状态

1. 补齐出生能量份额、低于50MeV/u的模型及连续cut的共同阈值支持；分离母能量分箱/步内能损误差。
2. 建立26组成的硬电离、轫致辐射率和可认证上界；条件终态与soft/hard能量划分保持一致。
3. 替换charged/photon终态和两种离子的出生读取，接入FP32worker，停止83节点查询。Joint原本只有25组成，保留空间推进和异质界面fallback。
4. 再进行GPU吞吐、队列/能量/EM审计及TOPAS对照；broadbeam local1%/1mm>99%，minibeam local3%/0.2mm>99%，搜索0.1×DTA。既有head minibeam绝对门槛未通过的事实单独报告。

本轮未运行新的GPU剂量对照，未改默认预设、评分精度、普通电子步长或joint步长。当前83节点对照二进制已冻结在`out/electron_compact_runtime_20261005/control83_carbon_mc`。所有原始结果位于`out/electron_continuous26_20261005/`。
