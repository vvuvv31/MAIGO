# TOPAS 与 MAIGO GPU 的物理过程实现对比

本文描述 2026-10-12 当前代码与八个发布预设。TOPAS 侧以仓库采用的 OpenTOPAS 4.2.3 / Geant4 11.3.2 提取工具和实际参考输入为依据；具体病例仍以其物理卡、可执行程序和启动进程日志为准。

**MAIGO 使用从 Geant4 提取并经离线处理的数据，在 GPU 上实现专用输运。它没有在 GPU 上执行 Geant4 本身。** 数据来源相同，不代表步进、末态抽样、输运范围和剂量估计量逐步相同。两者比较的是相同源、材料、几何和归一化下的物理剂量。

## 1. TOPAS 参考究竟启用了什么

TOPAS 没有唯一固定的物理列表。物理提取卡与患者剂量参考卡也不能混为一谈。例如，continuous26 离子电磁提取只需要 `g4em-standard_opt4` 和 `g4decay`，不包含完整患者核反应配置。

当前 20022516 质子微束 1B 全计划参考的模块为：

```text
g4em-standard_opt4
g4h-phy_QGSP_BIC_HP
g4decay
g4ion-inclxx
g4h-elastic_HP
g4stopping
g4radioactivedecay
AllChargedUrbanPhysics
```

该参考设置 `CutForAllParticles = 0.05 mm`、`EMRangeMax = 10 GeV`。这是一个具体参考实例，不是对所有历史 TOPAS 结果的统一描述。

`AllChargedUrbanPhysics` 会替换已有的带电强子 MSC 为 Urban，设置其高能上限为 10 GeV，并移除被替换进程管理器中的独立电磁 Coulomb scattering 伴随过程，以避免与 Urban 角尾重复。**它不删除强相互作用核弹性。** 实际替换了哪些物种，可从启动时的 `MAIGO Urban replacement` 日志确认。

碳离子还需检查 GenericIon 的实际核弹性注册。仅有 `g4h-elastic_HP` 名称不能证明 C12 核弹性已启用。仓库提供 `CarbonIonElasticPhysics`，调用 `G4IonElasticPhysics` 并检查 GenericIon 进程；[检查脚本](../scripts/check_topas_carbon_reference.py)可核查对应日志。历史参考没有该进程时，不能作为当前开启碳核弹性的完整匹配参考。

## 2. 主要物理过程对照

| 过程 | TOPAS / Geant4 参考实现 | 当前 MAIGO GPU 实现 | 具体差异 |
|---|---|---|---|
| 材料与密度 | 在几何中定义实际材料，建立对应物理表 | CCTG 保存 CT 几何、实际密度和 Schneider 25 类材料标识；continuous26 加入 Water_75eV | GPU 采用固定组成集合和连续密度查询，不支持运行时任意材料建表；水参考 I=75 eV |
| 离子连续电离能损 | 所选原生电离过程计算受限能损，使用其模型和能量相关物理表 | EMCNT001 continuous26 查询受限阻止本领、射程、反射程和相关参数，执行专用分步能损 | GPU 采用查表、插值和分步近似，并保留硬反应率及条件终态的标定近似 |
| 阈值以上 δ 能损 | 按生产 cut 和所选模型产生或处理电离次级电子 | 使用 delta moments、离散候选或聚合能损路径，具体由管线决定 | 聚合路径不是逐个 δ 电子的完整能谱抽样；电子是否空间输运另有开关 |
| 主粒子能损涨落 | 按实际挂接的离子电离涨落模型执行 | 八个预设默认保留；微束铜主粒子也保留 | 保留随机涨落不意味着每步分布与 Geant4 完全相同，尤其聚合 δ 两矩近似 |
| 次级离子能损涨落 | 通常随原生电离模型执行，不施加 GPU 的统一次级关闭策略 | 八个预设默认关闭患者/水内次级离子的受限连续及聚合 δ 能损涨落 | 次级仍输运、散射及发生核反应；只是相应能损采用均值 |
| 宽束库仑多重散射 | 由物理列表决定 MSC 与可能的独立 Coulomb scattering 组合 | Gaussian Fermi–Eyges，联合抽样角度与横向位移 | Gaussian 近似不等同于 Geant4 MSC 的完整角尾和步进算法 |
| 微束库仑多重散射 | 匹配参考使用 AllChargedUrbanPhysics；其他历史物理卡可能不同 | Geant4 Urban 数据驱动的专用更新，包含材料/物种 MFP、射程及真实/几何路径处理 | CT 的 continuous26 注册物种以实际密度查询受限阻止本领、射程及反射程；额外弹性反冲保留独立原生上下文；散射 MFP／辐射长度按密度缩放。专用更新、包内近似及 FP32 运算仍不与原生 Geant4 逐步等价 |
| 核非弹性反应率 | 查询实际物种、靶核和模型的数据集 | SCHNRATE v3 及当前次级反应率包，按组成和实际密度计算宏观反应率 | 固定包覆盖、能量查询和插值；不在 GPU 上调用原生核截面模型 |
| 核非弹性末态 | 在线执行所选强子/离子模型，产生反应末态 | 从有限相关事件库抽样，按能量节点选择并整体旋转至入射方向 | 保留库内事件的产物关联，但存在有限事件库及能量离散，不能生成任意新的原生末态 |
| 核弹性 | 对实际注册进程执行原生截面与散射模型 | 八个预设均加载各自质子/碳弹性与反冲包；根据靶同位素、动量转移和两体运动学生成散射/反冲 | GPU 使用有限样本及查表；核弹性与库仑 MSC 分开处理 |
| 核反应距离与过程竞争 | Geant4 进程管理器协调各离散过程的 interaction-length 状态和步长竞争 | 患者/水内主粒子、带电次级共用核光学深度函数，总率为弹性＋非弹性，碰撞时按率选过程 | 两者可以表示相同的竞争概率；GPU 共享一个核时钟，不复制 Geant4 的全部进程管理机制 |
| 带电碎片后续输运 | 按其注册过程继续输运和后续反应 | 支持的带电物种继续 EM、散射及允许的核反应；额外靶反冲使用反冲阻止本领路径 | GPU 按包的物种覆盖和明确策略执行，不能把它理解为只输运质子与 C12 |
| 次级核反应深度 | 按物理过程和轨迹终止条件继续，具体限制来自参考输入 | 患者/水内 `max_secondary_inelastic_generations: 2` | 达到上限只关闭新的非弹性分支，已有粒子继续 EM 和弹性；不把剩余动能直接全放在反应点 |
| 核中性产物 | 默认由相应 Geant4 过程输运；实际 killing/过滤策略须查参考卡 | 核中性产物不追踪，能量记为 untracked sink | GPU 不包含中子、核源光子等的空间剂量；不将其能量替换为局部沉积 |
| 衰变与停止过程 | 参考列表含 decay、radioactive decay、stopping；实际按适用物种执行 | 没有与这些模块对应的通用原生过程管理器或衰变链输运 | 核事件包的产物记录不能视为已实现完整后续衰变、捕获与中性输运 |
| 显式电子与电磁光子 | 依据原生 EM 模型和生产 cut，输运产生的电子/光子 | 不提供显式电子/光子输运或数据包加载路径 | 把患者/水介质内离子电离能量按局部路径记分，保留离子电磁能损；不等同于 TOPAS 显式电子结果 |

“默认关闭电子”和“不追踪核中性产物”是两件独立的事。开启电子包后，电子电磁过程中产生的光子有对应的输运路径；这不会恢复中子或核反应中性产物输运。

## 3. 离子能损与步进中的专用近似

额外靶反冲采用 `ELRSP001` 中对应同位素、材料及能量的总电子＋核阻止本领，并乘局部密度。步长限制和中点能损使用同一数据源；不为这些额外反冲虚构离散弹性/非弹性率。已删除原来以反冲包限制步长、却以水中质子参考表扣除能量的不一致路径。原始能量、原子核质量、主粒子涨落和铜准直器模型不变。

宽束聚合 δ 能损以一阶、二阶矩构造随机能量转移。适用时采用 Gamma 分布，形状为 μ²/v，尺度为 v/μ。它保留均值和方差，但不保留逐碰撞抽样的零事件概率及全部高阶矩。关闭显式电子空间输运不等于删除这部分离子能损。

关闭显式电子输运的质子 CT 宽束主粒子还对 Glandz 受限电离的密集显式尾部作聚合：当其 Poisson 均值 `p3≥4` 时，以复合 Poisson 的均值和方差构造一次 Gamma 抽样。该近似保留主粒子随机涨落，但不保留零事件概率和全部高阶尾部矩。低 `p3`、碳主粒子、水、微束及通用路径保持原显式 Poisson/能谱抽样。RT07575 头部优化计划的配对实现检查中，BODY≥0.4 Gy 的 local 1%/1 mm gamma 两轮均高于 99.95%；该参考是历史优化权重加权 TOPAS spot 库，不是本轮独立 TOPAS 重跑。具体范围与证据见 [质子宽束尾部聚合](proton_ct_broadbeam_dense_tail_gamma_20261013.md)。


CT 宽束局部电子专用路径还包含按分支启用的步首 δ 一阶矩、受限阻止本领近似，省去部分步内能量斜率评估。主粒子与碎片、质子与碳的实际启用范围以 `quality_report.json` 中的 `proton_ct_primary_first_order_delta`、`carbon_ct_primary_first_order_delta`、`carbon_ct_secondary_first_order_delta` 和受限能损相关条目为准，不能把某一条近似泛化到所有管线。

碳 CT 宽束主粒子保留受限能损和 δ 均值的步内斜率修正，不再使用上述两项步首近似；碳带电碎片与质子宽束的近似范围保持独立。该修改针对肺部沿束向剂量偏差，不改变硬反应率校准、核反应、主粒子涨落、电子开关或强制步长上限，也不表示质子微束肺部误差已经解决。

当前默认最大离子步长如下，水与 CT 一致：

| 区域 | GPU 最大步长 |
|---|---:|
| 宽束介质内 | 1.0 mm |
| 微束介质内 | 0.5 mm |
| 微束铜准直器 | 0.05 mm |

配置加载时强制覆盖相应 YAML 步长值。实际步长仍受几何、能损、散射和离散候选竞争限制，不等于表中的上限。CT 宽束当前快路径平均能损限制为 5%，不能用通用 `maximum_relative_energy_loss` 键代替实际分支规则。

TOPAS 的 `CutForAllParticles` 是次级生产射程 cut，**不是最大输运步长**。GPU 的 `energy_cutoff_MeV` 是离子终止参数，也不是生产 cut。三者不能直接互换。Geant4 的 EM 能量上限与 GPU 包的实际覆盖能量范围同样需要分别确认，不能仅凭一个 `EMRangeMax` 值判断全部过程一致。

## 4. 铜/空气上游与局部电离沉积

微束 GPU 显式处理铜、狭缝空气及患者前空气，四个预设使用 compact 上游/介质调度。进入患者的主粒子状态及带电核产物来自上游输运，不是只发射穿缝主粒子的近似。调度分离本身不改变源归一化。

四个微束均使用 `g4_delta` 统一铜涨落入口，主粒子按 Z/A 选择参数。`minibeam_copper_fragment_native_transport` 独立控制碎片原生 Urban／弹性路径，碳默认开启、质子默认关闭；原生碎片保留数据包标定。铜碎片受限涨落默认关闭，但 native 碳碎片仍保留硬 δ 的 Poisson/能谱抽样。铜 δ 电子能量当前按束线移除能量记账，不显式输运铜 δ 电子。铜碳碎片已有弹性＋非弹性共享光学深度，但仍使用铜专用实现；本轮公共时钟统一针对患者/水介质路径。

当前 GPU 不显式输运电子及电磁光子。患者内离子电离能损采用局部沉积，保留原能损抽样和切步时钟；因此与完整 TOPAS 的区别仍包含电子／光子空间再分布。历史电子开关比较仅对应其冻结版本。

## 5. 剂量计分与比较范围

TOPAS 参考使用对应的 DoseToMedium 计分。GPU 对体素沉积能量作 FP32 原子累积，再按体素质量和源归一化换算剂量；并行累加顺序可产生小的数值差异。本页既有验收限定为物理剂量。可选 `letd_output_prefix` 另行提供电子阻止本领的剂量加权 LET，独立保存分子、分母；其定义及匹配 TOPAS scorer 见 [LET 计分说明](let_scoring.md)。GPU 没有通用 Geant4 scorer 或生物剂量过程。

完整计划必须匹配束斑能量、位置、发射度、优化权重、CT 放置、铜几何、计分网格及原始入射粒子归一化。GPU 连续批次按全活动分配束斑粒子数并复用物理包；不能把已归一化计划剂量再乘批次数。RT07575 是头部病例，发布 CT 微束默认的独立肺部 benchmark 不能代替它的 full-plan 验证。

实现审计、GPU 新旧版本回归及 TOPAS 剂量验收分别回答不同问题。共享核时钟的本轮检查包括五管线编译、八预设共 16 批运行审计、零溢出，以及 10 万碳离子分段开/关的核事件与物种终止计数一致；这是实现检查，不是新增 TOPAS gamma 结果。历史 gamma 只对应其冻结的模型、参数、电子开关、源及统计量。
