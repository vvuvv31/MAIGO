# Class-II 弹性散射准备：原角度分布与输运矩

状态：已实现离线角分布积分并对照当前 FP32 GPU 单次散射抽样。
尚未实现凝聚输运、随机铰链/横向位移、接口策略或 CT 剂量验收；没有
class-II 吞吐结果。仍需完成原目标的 B1/B2/B3/C/D 等工作。

## 实际分布

令 q=1−cosθ、a 为当前能量下的 screening，屏蔽 Rutherford 的 CDF 为
u=q(1+a)/(2a+q)。在 u 坐标积分 Mott 接受率能处理很窄的前向峰。
以实际角度插值节点及对数 q 子区间拆分，独立使用16/32点 Gauss-Legendre。
现有 sampler **先选 Mott 能量行，再在该行进行拒绝抽样**，因此必须先把
每一行归一化，再按能量权重混合；直接混合接受率后统一归一化不是同一分布。

输出总分布和软/硬部分的概率、一阶输运矩 E[1−P1]=E[q]、二阶输运矩
E[1−P2]=E[3q−1.5q²]，保留82个节点的原始 SHA。使用原表转成 FP32 后的
表示值；积分本身在 CPU 高精度计算，不是 FP64 GPU 剂量计分。
连续重建分布与 GPU FP32 运算顺序的差异由独立抽样检查覆盖。

## 数值和抽样检查

- 82节点 ×37能量 =3,034条件，100.1eV–0.65MeV。
- 纯 Rutherford 解析矩用60位 Decimal 独立验证；最大相对误差4.333e-11。
- 完整 Mott16→32点积分（含截止角和分段矩）最大相对变化3.439e-11。
  软/硬矩闭合与目标90%概率均逐条件检查。
- 每条件16,384次当前 GPU 弹性抽样，共49,709,056次，全部有效，
  每条件 FP32 计数恰为16,384；种子先散列，再使用生产 LCG。
- 一/二阶矩与硬比例最大差异为4.811/5.562/3.974个标准误，均在
  7SE 组件筛选门内。第一矩用积分得到的方差，第二矩用样本方差，
  硬比例用二项方差。不是严格同时置信区间，也不是凝聚输运验收。

初版积分器曾保留错误数组轴，被软概率检查拒绝，已修复并保存。
线性初始种子产生分层早期随机数，不能使用独立历史误差解释；原样本保留
为诊断，散列种子重新检查。没有更改生产随机数。

## 对后续模型选择的影响

将90%事件划入软散射时所需截止角范围：

|电子能量|截止角范围|
|---|---:|
|100eV–1keV|41.1–129.5°|
|1–10keV|14.7–83.0°|
|10–100keV|4.35–25.61°|
|100keV–0.65MeV|1.37–7.01°|

不能在所有能量直接把90%事件套进小角高斯近似。这否定的是“统一小角”
前提，不是否定 class-II 方法。探索性限制软散射角≤0.1rad时，四个能量
区间的硬事件减少倍数中位数约1.03/1.30/4.24/10；这是角分布积分结果，
**不是实际步数或吞吐倍数**。当前诊断68.4%的 charged 调用位于10–100keV，
其可凝聚程度不能用最高能量段代替。

下一步需选择能量相关 cutoff 与有限角 soft 分布，保留随机位移及界面处理，
用原生横向/峰谷和材料界面检查后再接入 CT。B3 的弹性零碰撞及能损上限
调整仍应在这个基础模型验证后进行。
