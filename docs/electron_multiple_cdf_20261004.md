# 完整软散射卷积表：分量验证和内联优化

最终加密表通过数值、GPU 角度及空间矩筛选。内联并移除局部数组后，
孤立固定能量散射段耗时减少约 21.3%；这不是完整电子输运或 CT 的加速。
尚未接入正式内核。正式全 FP32、体素缓存版本保持不变，resident 约
111,082 primary/s，电子约 7.7931 s/批，1–2 s 目标未实现。

## 模型和适用范围

单次软角度服从现有截断 Rutherford + Mott 法则；分别归一化原生能量行，
保持先选择能量行再拒绝抽样的混合概率。使用球面卷积恒等式：若单次
Legendre 系数为 f_l，固定 N 次散射后的系数就是 f_l^N。它保留完整角度
分布，而不仅是前两个输运矩。

- 仅节点 12/32/57，能量 1/10/100/400 keV，共 12 个固定条件。
- 截角取 90% 分位角与 0.1 rad 中较小者；N=2–32，1537 概率节点。
- FP32 角度表共 2,287,056 bytes；这不是完整 CT 材料/连续能量包大小。
- N=0 直行，N=1 原软角度抽样，N>32 显式复合，未丢弃尾部。
- 两个半段独立抽 Poisson(μ/2)，采用乘积算法，避免累计概率尾部舍入。
- 总 N≤4 时，均匀抽取并排序所有碰撞位置，显式保留轨迹。
- N>4 使用两次半段完整角度和 Geant4 派生的 GS 空间公式。
- Q1=μ·mean(q)>0.02 或 μ>64 时回到原显式软散射；84 条件中 6 个
  μ=16 条件走此保护路径，不能计为 GS 覆盖收益。

这里只验证均匀材料、固定能量、0.05 mm 软散射段。尚无能损、硬事件、
光子、任意能量插值、材料界面、沿曲线路径沉积或 CT 剂量验收。
实现拒绝超过 0.25 mm 的段。

## 表精度与独立检查

2048 阶的谱收敛/单调修复不合格。4096 阶配 8193 个 CDF 构造点，
虽然网格内检查和 GPU 有限统计筛选通过，独立谱计算却发现约 10^-5
尾概率的相对误差达到 3.103%，超过预设 1%。因此撤回旧粗网格表的
数值验收；保留所有输出并登记 failed.md。这是概率误差，不是剂量误差。

最终版本使用 4096 阶、32769 构造点。每个固定 N 的逆表在 643 个独立
概率点直接计算谱 CDF，不再只与构造网格比较。只有全部门槛通过才导出
可加载的 index。最终结果：

| 检查 | 最大值 | 门槛 |
|---|---:|---:|
| 16/32 点积分的系数差 | 2.590e-13 | 1e-9 |
| 谱阶加倍的 CDF 差 | 3.311e-7 | 1e-6 |
| CDF 单调修复 | 5.127e-8 | 1e-7 |
| 输运矩相对误差 | 2.937e-5 | 1e-4 |
| 独立直接 CDF 误差 | 3.038e-5 | 1e-4 |
| 尾概率≥1e-5 的独立相对误差 | 0.24444% | 1% |

这些是离散分量筛选，不是连续域误差证明。最终表索引 SHA256：
`2de07ea802674f93be2bd5aa5bcf7811abbff8f7bf26db94bcd786af533a55e2`。

## 最终表的 GPU 复测

角度：408 条件，每条件每臂 32768 样本，共 13,369,344/臂。零无效，
理论方差下的一/二阶矩、精确二项尾概率检验、family alpha=0.01 的
两样本 KS 均通过。最大 KS=0.0131531。

空间：84 条件，每条件每臂 131072 样本，共 11,010,048/臂。角度/空间矩、
方向范数及弦长检查通过，最大径向 KS=0.00723267、角度 KS=0.00649261。
Poisson 计数和 N>4 概率的精确二项 family 检查通过。
径向最差条件的中位数差约 −4.47%；KS 并不等于分位数或局部剂量相对差，
不能据此宣称符合 CT 峰谷 1% 标准。

## 性能机制

最初完整原型比显式散射慢约 66%。PTX 显示 segment 未内联，设备函数
调用携带局部参数状态，低计数 positions[4] 也使用局部数组。原型约
116–118 寄存器、128 B 静态栈；参考 42 寄存器、0 B 栈。静态栈不是
动态寄存器溢出量。Nsight 实际启动记录显示，原型为 512 threads/block，
参考和后续内联版本为 1024 threads/block。

仅研究头文件新增两个编译开关：`CARBON_MULTIPLE_FORCE_INLINE` 强制
内联外层函数；`CARBON_MULTIPLE_SCALAR_POSITIONS` 用四个标量和排序网络
替换局部数组。二者保持逐历史结果及 RNG 顺序。内联后 56 regs/16 B 栈；
标量版 57 regs/0 B 栈。正式构建未新增这些开关。

夹具将入射方向作为运行时参数，对两臂均连续预热至少一秒，再做三次
ABBA；编译/剖析不与计时重叠。最终加密表：参考约 3.0605 ms，候选约
2.4098 ms，三次时间比 0.78787/0.78765/0.78661。孤立段耗时减少约
21.26%，吞吐增加约 27.01%。它不包含运行时能量定位、材料查询、能损、
硬事件和剂量计分；不得外推成完整电子阶段收益。
