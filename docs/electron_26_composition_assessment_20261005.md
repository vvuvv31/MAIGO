## 建议架构

1. 共用26组成的Urban/弹性角和光子质量反应率；轻量标量模型提供连续实际cut、密度效应和必要原生样条修正。
2. 共用终态使用组成与入射能量索引的能量—角度联合分布，实际cut作为额外查询/抽样参数。Photon优先研究：主过程率可共用，但产生电子/光子的阈值处理、能量分配和分支权重必须重建；不能仅丢弃低于cut的记录。
3. Charged硬电离/轫致辐射使用实际cut的过程率及条件联合分布；保持空碰撞majorant认证。受限停止、射程和能损涨落必须与硬过程划分一致。
4. Proton/carbon出生各保留26组成的母分布和连续cut修正。核能损到电子包的能量加权份额、能量—角度相关性和阈值支持不能只用参考CDF替代。两种离子的出生分布不合并。
5. Joint先保持已用组成参考密度缩放的模型。其进一步参数化压缩是另一项独立近似，不能把本轮26组成缩减比例再次套用。

目标可以做到“运行材料选择只有26组成”，允许小型cut参数表或拟合系数；不能把它称为完全不需要密度相关信息。相比离子解析新路径的吞吐下降，电子模型必须避免在每个worker微步重算昂贵积分或多项式：优先入队/材料变更时计算标量，硬事件发生时才处理条件分布。

## 后续优化优先级：先减少重复终态，再收敛到26组成

检查当前编译器和抽样器后，建议调整实施顺序；避免一开始就引入全套解析电子输运。

1. **直接运行格式。** 当前磁盘终态为32字节（FP64 CDF/能量比例/角度），加载后转为64位整数CDF阈值＋FP32能量比例/角度。直接保存与当前转换逐位一致的运行字段，绕过FP64临时设备/主机对象和重复转换。64位CDF阈值保留，不能直接降到FP32概率。相同终态按24字节运行布局约减少25%；这是格式上限估算，不是整个包或已测GPU峰值内存的减少比例。若逐位重现已转换字段，可以先做表示一致性检查，而不引入新的物理拟合。
2. **合并同通道局部终态。** Photon共有57,306,013条终态，其中18,824,493条pdg=0（32.8491%）。每个通道合并局部沉积概率后，记录体积预计减少约600.336MB（按现有32字节估算，扣除每通道一条的保守估算）。Charged只有276,358/17,637,382条局部终态，类似收益约7.478MB，不是主攻点。当前pdg=0分支在相互作用位置沉积包权重，不继续传播；需逐路径核对物理能量、统计权重与诊断账本，才可以认定合并保持原有估计器。采用当前整数CDF区间质量可避免概率重归一化误差；重排会改变同一随机数对应的结果，不能要求同seed剂量逐位一致。
3. **小型联合分布替代剩余大CDF。** 先维持所有原密度节点，让“分布表示变化”与“密度模型变化”独立验收。按过程和pdg分组，保存分支总概率及能量—角度相关的自适应二维分布；局部沉积分支单独处理。保留稀有大角度/高能尾部，不能用独立一维边缘谱或均匀reservoir替代。既有failed.md中的尾部和跨能量失败条件仍适用；这是变化后的条件联合分布方案，不是重复被否决的等权抽样。
4. **26组成＋连续cut。** 在压缩分布通过后，将相同组成的分布用实际electron/photon cut索引，减少重复密度节点。光子质量反应率和Urban标量共用；charged stopping/range及硬过程率保留连续cut/density修正。出生包按proton/carbon分别处理。拟合和积分主要离线完成；每微步不能重新计算复杂积分，否则可能重演离子26组成路径的吞吐下降。
5. **Joint单独处理。** 已经是25组成；它的1.424GB体积不能靠删密度节点解决。先保留当前模型，再研究子图共用和保留相关性的压缩。普通步与终止/产生子粒子的步分开处理，不能恢复已失败的无差别抽薄。

前三项有助于减少读取、转换、随机大表访问；对完整worker吞吐的收益仍需剖析与GPU实测。Photon当前终态使用mapped host USM，压缩并能驻留显存可能减少跨PCIe访问，但是否为主瓶颈尚无本轮硬件计数器证据。不预先承诺primary/s提升。
