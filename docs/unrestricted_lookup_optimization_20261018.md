# 通用查表优化实验（2026-10-18）

本轮三个候选均未采用。正式核心源码仍与此前已接受的 unrestricted 步内共享区间求值基线一致；108 个核心／配置／构建文件的 SHA256 已核对。保留用户既有的 unrestricted 迁移，没有重置工作树。

## 候选与结论

1. **CT 核反应查询专用化**：在主机已证明为 CT 的内核中移除水分支。281 万次查询、3937 万次浮点比较逐位一致。L4 质子宽束正反顺序合并 −0.21%，A6000 −1.68%；碳宽束初测仅 +0.26%／+0.48%。没有稳定收益，已撤回三个源码文件。静态 PTX 中较少的 FP64 指令主要来自冷分支消失，不代表动态 FP64 成本下降。

2. **额外指针版射程索引**：只缩小原始反查区间，保留节点和公式；增加约 0.46 MiB 派生索引。A6000 质子／碳宽束双顺序分别 −3.00%／−1.40%，没有采用。该布局增加临时视图指针与静态栈；没有动态 spill 证据，不能据此确定变慢原因。

3. **紧凑版能量—射程索引**：两行索引共用现有指针，保持视图、轨迹状态大小及关键内核寄存器／静态栈不变。200 万个状态、1201 万次反查、3407 万次浮点比较逐位一致，含非线性密度修正。实际吞吐仍没有稳定收益，未合入正式源码。

原 RT07575 **头部**计划源。每进程三批连续运行，首批排除；热吞吐为后两批粒子数除以其总 wall time，包含审计和剂量输出。初测变化超过 1% 时，用另一组三批独立种子反向复测。所有行均为同卡、同源、同种子的实现比较，不能用于推断显卡峰值 FP32 比例。

## 正确性与硬件诊断

紧凑版有效 GPU 测试共 556,854,384 histories、60 个 field-batch、8 组配对，源 CSV／配置相同。能量、覆盖、完成、EM／Urban、核反应／弹性及所检查的 live-ion／离散计数通过，队列零溢出。最大剂量相对 L1 差异 1.471e-07，最大运行能量残差 3.724e-06；高于 10% Dmax 的同体素 local1% 实现比较均为 100%。这是 GPU 实现一致性检查，不是新增 TOPAS gamma 或八预设验收。

没有改变物理、随机序列、步长、primary 涨落、secondary 涨落开关、源权重、归一化或 FP32 剂量原子操作。三个架构均完成全五管线 AOT 构建（sm_75／86／89），所有 GPU 执行均设置 `CUDA_DISABLE_PTX_JIT=1`；2080Ti 只编译，保持停算。

L4 Nsight Compute 的首个过滤器未选中内核；改用完整名称后，采样器在准备内核时失败，未取得动态硬件计数。因此本轮不能确认访存、分支或 FP32 单元中哪项是硬件瓶颈，也没有证明 L4 可达到 2080Ti 的两倍吞吐。诊断计时均排除。

L4 会话 `maigo-fp32-l4-20261018` 保留，收尾时 GPU 空闲；本地和 A6000 也没有本轮遗留的 GPU 计算。既有 TOPAS 和暂停的完整计划调度器未改动。
