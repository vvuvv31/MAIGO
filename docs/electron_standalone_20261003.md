## 新出生包与实现

- 包：`out/electron_standalone_20261003/birth_bank64/birth_bank.bin`
- 328,367,136 bytes，313.155 MiB，82 节点、每节点 64 个独立 proton 历史；共 13,675,048 个电子出生样本。
- SHA256：`a6215fb92e70dd67eb12d5118727ff23acf5191fca34c0ab53b02673bc808979`。
- 每节点 50 个 5 MeV primary 能量箱；保存原生能量份额和按电子能量加权的 `(Eelectron, cosθ)` 联合 CDF。未做轨迹/样本分层压缩。
- 出生规律在每个实际密度重新提取：固定物理 production cut 会改变出生谱，因此不能仅按密度缩放出生分布。节点间使用能量份额加权的密度混合。
- 新 scorer 不消费 RNG、不杀轨迹、不改变输运；原生提取无 GS override。4 个代表节点与完整输运记录逐出生核对，能量完全一致、角度差 <1e−12，并核对所有 primary 分箱能量。
- 队列 birth payload 仍 48 bytes，整个 task 仍 128 bytes；group32 不变。
- 接口：`material_electron_birth_file`、`material_electron_birth_sha256`。必须同时配置已有 joint pilot；每个保留上下文只加载一次新出生包，连续 fresh 批次确认 cache hit。
- 新出生构造位置、方向和动能；如果 joint 入口的同质检查不通过，显式按当前状态绑定旧 continuation，**不读取旧 birth reference**。因此日志 `legacy_birth_reads=0` 仅表示运行时出生采样已绕开，并不表示不加载旧文件或不调用旧输运。

生成/运行入口：

```bash
python3 scripts/build_electron_birth_native.py
python3 scripts/extract_electron_birth.py --out <新输出目录> --histories 64 --workers 3
bash scripts/build.sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/run_independent_birth_screen.py \
  --shards 10 --out <新对照目录>
```

原生 build 复用已固定的本地 TOPAS/Geant4 静态库；具体命令和来源散列在 `native_build/build_manifest.json`。原生提取比较采用完整记账，不是 GPU FP64 剂量评分。GPU 始终 `CARBON_DOSE_FP32=ON`、`CARBON_DOSE_FP64=OFF`。

## RT07575 出生采样对照

控制组是 **旧出生 + 新 25 材料 joint + 原界面回退**；实验组只替换出生采样。因此不是新模型相对 TOPAS 的 gamma，也不是完全独立输运与旧全路径的比较。

最终对照：`out/electron_standalone_20261003/rt07575_birth_20m/report.json`。

- 每组 19,839,200 primary，10 个相同源/种子配对；交替组顺序、同进程 20 批次，group32。
- frozen GPU binary SHA256：`ebfe32c94f416c46b558de40f1652433b21e440ab71a53cb0a4a717de99bccd4`。
- 所有 20 批 quality/能量/队列检查通过；invalid=0、overflow=0；primary 输运和 EM 审计逐配对一致。
- 关闭新 birth 后，相对既有 Schneider batch0000 的剂量 relative L1=8.056e−8，符合 FP32 累加次序差异。
- BODY（含 GTV）剂量绝对差总和/对照剂量总和：**0.206403%**；全网格为 0.819496%。此前每组 396.8 万的 BODY 值为 0.436573%，表明运行抽样差异仍明显。不能据此排除有限训练样本的系统偏差。

## 独立界面数据

入口：`scripts/extract_electron_interface.py`；完成结果：`out/electron_standalone_20261003/interface_12/report.json`。

- 4 个材料方向：肺→软组织、软组织→肺、软组织→骨、骨→软组织。
- 使用真实 Schneider 节点 57/12/32，密度约 0.299416/0.998911/1.532247 g/cm³；保留各自 I 和组成。
- 每方向 3 个条件：距平面 0.001 mm 正入射、0.01 mm/80°、0.049 mm/90°，角度相对界面法线。
- 请求 0.4 MeV；每条件 2,000 histories，共 24,000 histories。记录实际 TOPAS 浮点源状态，并按实际 KE 做逐历史能量账。
- 原始 opt4/GS，无 override；native MaxStep=0.05 mm、cut=0.05 mm；双材料相邻实心盒，真实 Geant4 导航和跨界，非事后裁切轨迹。
- 12 条件均通过逐步/逐历史能量、完整子粒子出生、轨迹连续性和步长审计；共 **28,844 次跨材料事件**，包括同历史回穿；没有删除任何电子/光子分支。
- 每条件保留 `steps.phsp` 全原始图、`first_steps.npz` 条件首步与所有首步子粒子状态及来源行。NPZ 未做有损压缩。

**这些仅为平面界面参考数据，尚未形成 GPU 界面模型。** 不能将首步样本直接当成所有 continuing 状态；还需区分进入边界时的散射状态、距离与入射方向，覆盖能量、密度及 CT 棱角/多界面。有限盒逸出仅是该参考夹具的能量出口，不是患者光子逃逸结论。
