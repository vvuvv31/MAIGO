# CT broadbeam 主粒子涨落抽样优化

主粒子能损涨落保持开启，次级涨落和电子运输关闭；核弹性开启，宽束步长上限仍为 1 mm。以下测试均为 RTX 2080 Ti 上 RT07575 **头部**完整计划，不能当作默认肺部配置或其他 GPU 的验收。

采用的优化：

- 质子、碳离子 CT broadbeam 的电子关闭主粒子路径使用 Giles 八阶逆 erf 正态抽样，只消耗一个受保护的均匀随机数。完整 24-bit 网格 GPU 检查：无非法值或非单调点，最大 CDF 误差约 6.83e-8。
- 质子该路径额外采用 CUDA native log/exp/sqrt，以及小形状 Gamma 的 native powr；碳离子保留标准数学运算。拒绝抽样规则保留。小形状幂运算单项 ABBA+BABA611868→629161/s（+2.826%），四个配对正向；两组gamma99.950731%/99.956142%，解析矩检查maxmeanZ1.436/maxvarianceZ2.037，invalid0。
- 质子受限电离显式尾部仅在 p3≥4 时用匹配均值、方差的聚合 Gamma；**改变零事件概率及高阶矩**，不是完整分布等价。独立受限能损矩检查通过，单项配对收益 2.937%。碳离子同方案收益不稳定，未采用。
- 实际材料和密度的射程节点缓存，解析逆算采用质子 2 次、碳离子 3 次更新，保留相同 1e-6 残差保护和原 5 次更新回退。

额外修复了共享通用反冲离子能损：之前 ELRSP001 的同位素/材料/密度中点阻止本领只用于检查，实际能损误用了无密度缩放的水中 H 曲线；现使用已经算出的正确中点值。移除其旧运行时读取器及配置键，铜中的物种阻止本领仍保留；water/ions.csv 仍是离线铜 δ 校准资产。这是物理修复，其他六个预设的剂量也可能变化。

最终直接比较使用保存的标准正态抽样基线，候选为完整五管线 build/carbon_mc；包含上述多项变化，不能把总收益归于某一个抽样器，也不能相加各项增益。ABBA＋独立种子 BABA，各 arm 模拟 3600 万、稳态计时 2400 万；独立剂量统计为 600 万和 1200 万，同种子重复计时不增加统计量。首次 batch 吞吐不等于进程冷启动。时钟未锁定，不作硬件因果归因。
