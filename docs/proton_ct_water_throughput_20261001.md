# Proton minibeam：CT 与 water phantom 吞吐实测（2026-10-01）

当前预设下，water 吞吐为 CT 的 **5.67 倍**；CT 吞吐低 **82.4%**。

## 测试条件

- GPU：单张 NVIDIA GeForce RTX 2080 Ti；Release，FP32 dose ON / FP64 OFF。
- 同一个最终交付二进制；170 MeV proton，compact minibeam；Water_75eV，stopping scale 1.0。
- 每项 3 次，每次 2,000,000 入射历史；同对使用相同种子 100114001 / 100114002 / 100114003。
- 执行顺序：water→CT、CT→water、water→CT；串行运行，无并行 GPU 压测。
- 每次启动独立进程，保留加载、输出和退出开销；没有清空操作系统文件缓存，也未锁定 GPU 时钟。
- 吞吐定义为总完成入射历史数 / 总墙钟秒数，不是进入模体的幸存粒子数 / 秒。
- 二进制 SHA256：`8c52a6b117579bdb2a381d67811e1d0d047a65d275c204115c36f099ef91148a`。

汇总吞吐：water **122,371 histories/s**，CT **21,582 histories/s**。

遥测覆盖初始化与运行：water温度31–84°C，CT为43–83°C；首轮从冷卡开始。
各对吞吐比为5.59–5.82倍，足以确认本次大幅差距，但不用于解释百分之几的细微性能变化。

表中完整输运循环是汇总行，不能再与其内核子项相加。water 的水电子响应包含在介质 kernel 内，独立队列为零不表示关闭电子响应。
只计输运循环，water 为 165,779 histories/s，CT 为 28,639 histories/s，相差 5.79 倍。

介质主粒子 kernel 时间相差 8.38 倍；铜/空气仅相差 1.11 倍。CT 还承担独立材料电子响应队列和更长初始化。主要耗时差距出现在公共上游之后。
