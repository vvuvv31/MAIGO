## 稀疏 EM 周期采样

每个次级步用独立 Philox 身份标签选择约 1/1024 的步，不消耗输运随机流。对 prepare、mean、受限涨落及 delta 聚合记录 clock64 差值，按统一 EM 包的 18 种离子索引累加。总采样 1,396,207 步，其中 H1/H2/H3/He3/He4 占 94.49%。

| 区段 | 四个被测区段内采样周期占比 |
|---|---:|
| prepare：两个密度节点的参数查表与准备 | 46.32% |
| 受限能损涨落及相邻控制逻辑 | 32.15% |
| mean：平均能损及相邻运动学计算 | 12.23% |
| delta 聚合及其矩计算 | 9.30% |

这不是端到端运行占比。clock64 包括等待、warp 调度和分支影响；采样插桩本身增加控制/寄存器开销，prepare 后统计原子操作也可能影响后续缓存。未覆盖 MCS、核反应率、几何和记分；不得直接将百分比作为模块删除后的提速上限。只支持优先研究参数准备和受限涨落，尚不能断言 Universal 分支在受限涨落中占多少。

诊断质量通过、零 overflow；EM 审计与无采样基线逐项一致，最大同体素剂量差为峰值的 0.0000497%。此为 GPU 自对照，不代替 TOPAS BODY Gamma。

### 下一候选：Universal 显式求和的条件分布

不重做已否决的单独 Poisson 反演或 RNG 替换。若继续容许受控物理近似，应优先评估 Universal 中
`w3 * sum(1 / (1 - w * U_i)), i=1..N` 的条件分布重放：保留其与 Poisson N、w、w3 的关系，先研究归一化和分位数表的尺寸/误差，再决定是否实现。

这能同时针对不定长求和和随机调用，区别于单纯替换 Poisson。不得直接以均值或一个高斯替代。研究阶段需额外捕获实际 N/w/w3 分布，覆盖 N=0/1、小 w、w 接近 1 及表外回退；验证条件均值、方差、尾概率、能量封顶、与其他涨落分量的联合独立性及表插值连续性。

即使边际分布匹配，新算法消耗随机数不同，也会改变后续抽样轨迹；应显式记录这一点，不再要求逐条同 seed 剂量相同，而改用统计验收、完整剂量/Gamma 与水模峰区验证。现阶段只完成归因及重放，未实现或启用这一近似。


## 第三轮：保留 Poisson N 的条件求和表（已评估，不推广）

证据目录：`scratch/em_cost_20260916/fluctuation/conditional/`。通过 GPU 重放提取原算法真正抽到的 N、w、w3 和 Poisson 均值，不以 CPU 近似重算替代。提取后仍精确复现全部 86,860 条原始 loss。

### 参数与候选

69,475 条复合分支中，N 中位数 8、P99=15、最大 24；R=1/(1-w) 中位数 20.96、P90=64.06、P99=543.50、最大 7,469.82；Poisson 均值中位数 7.9658。大 R 的长尾不适合直接均值化或高斯化。

候选仅替换 `sum(1/(1-w U_i))`，保留原 Poisson N。N=0/1、N>24、R>128 使用原算法。对 2<=N<=24、1<R<=128，采用 Z=(X-1)/(R-1) 的条件和分位数表；Z 的精确 CDF 为 `R*z/(1+(R-1)*z)`。以精确单项分箱概率、FFT 卷积生成条件和 CDF，存储 29 个 log2(R) 节点 × 23 个 N × 4,121 个概率节点的 float 表，共 10,994,828 字节。中央概率等距、两侧加密，插值后恢复原尺度 w3。

直接对未归一化和插值在 R 接近 1 时导致很大的方差/CDF 误差，因此放弃该版本；最终仅保留上述归一化版本。覆盖实际复合分支样本的 94.78%，占全部捕获输入的 75.81%。

### 有限区间的误差检查

表生成每个单项使用 16,384 个归一化格；验证在相邻 R 节点的几何中点以 32,768 个格独立卷积，遍历 N=2..24。与解析矩及数值 CDF 比较：

- 表节点条件均值最大相对误差 0.00536%，方差 0.0700%。
- 所测 R 中点条件均值最大相对误差 **0.1599%**，方差 **0.1319%**，CDF 最大差 **0.001945**。
- 参考 99%、99.9%、99.99% 分位点处，超阈概率最大绝对差分别为 0.0001296、0.0000368、0.00000634。

这些检查仅覆盖上述网格与参数区间；不是全域严格误差界，也没有验证材料边界、整条轨迹或患者剂量。表是研究派生物，不属于已授权生产数据包。

## 第四轮：联合 compound-Poisson 表与完整输运筛选（停止）

### 方法及局部误差

联合抽样 Universal 显式部分 `sum_{i=1..N} X_i`，N~Poisson(lambda)，X=1/(1-wU)。适用 lambda∈[4,8]、R=1/(1-w)∈[2,128]，其余路径保持原算法。用 exp(-lambda) 显式处理零事件概率，正值部分按条件分位数抽样；原有激发分量、Gaussian 分量及 delta 聚合均保留。覆盖捕获复合分支样本约 94.05%。

按精确单项分箱概率，通过 `exp(lambda*(FFT(pdf)-1))` 生成分布，并去除零点质量；有限 FFT 周期与离散化意味着它是数值近似而非精确采样器。表在 R、lambda、概率三个维度插值，正值分位数先按条件均值归一化。

初版 25×17×4,121 float，7,005,700 字节；随后将概率节点压到 1,053，保留两侧加密，表降到 1,790,100 字节。小表在 24×16 个参数单元中点，以加倍分辨率独立 FFT 验证：条件组合后均值最大相对误差 0.0141%、方差 0.3457%、CDF 最大差 0.001678；99%、99.9%、99.99% 分位点的超阈概率最大绝对误差分别为 0.0001439、0.00003136、0.000006337。

误差仅针对测试区间与节点，不是全域严格界，也不是输运精度验收。正值最小支持经插值约为 1.00053 而非精确 1，属于尚需控制的分布近似。

### 独立 GPU sampler

四轮交错真实输入重放：大表 sampler 吞吐提高 7.67–9.26%；小表提高 11.28–12.83%。输入均为此前 86,860 条次级真实输入，全部输出有限、有效。不能用一组输入的能损和接近证明分布等价；新算法消耗随机数不同。

### 下一方向：先测区间索引的跨步复用率

覆盖边界只省端点查询，未省 prepare 中真正的节点/分段定位。下一候选应先采集相邻步的材料/密度状态、node 和 cubic segment 索引变化率，再决定是否实现精确区间缓存：优先检查上一索引仍覆盖当前能量，否则邻区探测或回退现有精确搜索。必须保持节点边界等号语义、材料变化时失效、两密度曲线独立处理以及原插值运算顺序。

先用独立采样估计可省搜索次数及所需状态，不直接增加生产轨迹结构。若复用率低或状态导致 occupancy/访存恶化即停止；若实现，完整 shard 穿插 A/B 必须显示超过运行波动的总耗时收益，审计一致且剂量差不超过 baseline 重复量级。未测到收益前不承诺加速比例。暂不追加大分位表、放宽步长或粗化 CT 边界。
