# FP32电子跨步体素与材料缓存

本轮研究同一体素内的重复几何和材料查询，不改变步长、散射角度、能损、
硬碰撞、光子分支或随机数消费顺序。完整RT07575 ABBA已通过，现已纳入
`scripts/build_options.json`默认构建和`build/carbon_mc`。

## 实现与边界

每个worker保存最近体素的材料密度模型、硬速率上界和六个物理边界。
只在位置严格位于该体素内部、到各面距离大于0.05mm加FP32舍入余量、
方向满足原范数契约时，省去两次射线边界查询。其余位置使用原几何方法，
将得到的同一个face传入原步进公式。材料模型仅在体素索引不变时复用。

缓存属于一个不可变geometry/bank，取新任务时失效。joint或photon改变
位置后仍检查物理边界，不能凭上一步的face标志判断是否还在旧体素。
没有移动粒子、忽略散射或按射程跳过横向位移；即使浮点步进端点恰好落到面上，
下一步也会回到原边界查询。几何guard绑定原0.05mm默认最大步长；生成器
检查该默认值，不能在改大步长后无验证地沿用guard。

这不同于已否决的“只复用同一步face”实验：现在跨步省去密度查找、密度模型
构造、硬速率上界插值，并在严格内部跳过射线距离计算。它也不是新凝聚散射近似。

`generate_electron_voxel_cache.py`从当前生成的FP32步进和packet方程抽取
保持相同运算顺序的副本，只替换face及材料准备；`--check`检查同步。
CMake实验开关为`CARBON_ELECTRON_VOXEL_CACHE`，关闭时两个运行时源文件
经移除该条件块后与实验前逐字节相同。剂量一直使用FP32 atomics。

## 分量对照

139个密度条件（82原生节点和57节点间密度），284672个电子包，44500813步。
3×3×3异质体素，0.02/0.5mm间距，坐标原点包含−169.1015/300mm，初始位置
覆盖体素内部、精确面及其两个相邻FP32坐标。方向和能量覆盖现有原语范围。
部分历史中人为位置跳转检查缓存失效；这不是一个新的物理过程。
光子交接后结束此夹具，完整photon/joint耦合另由整批测试检查。

- 每步packet状态、位置、方向、能量、材料、计数及最终RNG全部相同。
- 审计计数全部相同，零无效轨迹、零步数上限触发。
- 每次guard命中都用原函数复核体素和材料，以及原face距离严格大于0.05mm。
- 14417481次几何guard命中，约32.4%的全部步。
- 43577415次材料复用，约97.9%的全部步；892107次更新。

这些比例来自合成夹具，不代表RT07575覆盖率，也不能直接换算成速度提升。

证据：`out/electron_voxel_cache_20261004/fixture_report.json`、原始log、
`off_source_check.json`、`candidate_source/`；构建失败的第一版命名空间也保存，
未使用其任何运行结果。
