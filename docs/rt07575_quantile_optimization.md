# RT07575 50k/s：δ 总损失分位数表研究（2026-09-14）

本轮没有达到50k/s，也未通过剂量精度门槛。候选仅在独立源码/构建中运行，正式源码、物理包和配置未替换，没有commit/push。

## 实现

原生δ候选能谱在固定局部状态下构成复合泊松总损失。以Tmax/cut、beta²和碰撞期望数为参数，FFT计算总损失分布，再保存正能损部分的逆CDF；零事件质量单独处理。运行时不逐个抽取电子，而是抽一个总损失。原Tc以下受限连续能损及涨落仍计算，δ总损失另外加入一次，不做漏算。

此轮在满足范围条件时合并完整有限δ谱，而非只合并固定4倍cut以下的软部分。最初版本对期望数做分位数线性插值，阈值附近的离散峰和尾部失真；最终改成相邻期望数节点的概率混合，并细化sqrt(mean)网格。该混合有额外微小方差及零事件概率误差，已量化，不宣称严格等价。

- 相空间：R=1.01..64，beta²=0..0.9，mean=0.001..32；运行使用更窄范围，越界/近停止区域回退原逐次抽样。
- 宏观步限制：0.5 mm、预估平均能损0.5%、proposal期望数24，随后仍受几何与核碰撞截断。
- 谱表采用归一化spin-zero pre-veto核；忽略的自旋/磁矩/形状因子项仅在估计上界小于1e-4时允许。它是显式研究近似，不继承原统一包的生产授权。
- 最终版本的δ率/谱冻结在步首。原始受限连续涨落改为在宏观步上抽样；这改变了联合涨落和有限步近似，是未通过精度验收的重要待查因素。
- 所有原统一EM及Schneider v2.1 SHA检查保留。额外分位数表也绑定SHA；事件计数不把一次总损失抽样伪装成一个真实δ电子。

## 数值检查

采用更细网格的独立FFT参考，在256个随机表内状态上检查插值；这些检查不能替代输运精度。
- mean_rel 最大绝对值：0.00070108457。
- variance_rel 最大绝对值：0.0015685849。
- zero_absolute 最大绝对值：0.00028861765。
- tail_cdf_error 最大绝对值：0.033542406。
- 在阈值附近，正能损条件分布很窄，条件CDF的网格误差较明显；稀有离散峰的相对分位数误差不能直接解释为总剂量误差。表还需要更强的边界/尾部验收。
- GPU 100,000次插值与host对照：最大相对差约2.93e-7。
- 不把上述随机点检查称为所有材料、所有能量的完整闭合。

## 后续需要改变的层级

50k/s约需把百万原发的总耗时压到20s。当前候选kernel仍约59s，仅继续压缩查表成本不够。后续更合理的是复用/预计算原EM微步的联合传播：同时保持受限连续涨落、δ损失和末端能量分布，再减少外层几何、核率准备及散射更新的重复工作。只独立匹配δ损失均值、方差，不能保证整体射程涨落与原算法一致。

原先完全删除δ的56k/s是物理被改变的诊断参考，不是本轮精度合格的结果，也不是保证能达到的优化上界。
