# CT minibeam 患者内缓存与射程逆算优化

已将关闭电子运输的 Proton/Carbon CT minibeam 患者内主粒子接入现有实际材料/密度缓存、主粒子射程节点缓存和解析逆算。Proton CT minibeam 使用主粒子弹性总率缓存；Carbon CT minibeam 使用主粒子和全部18种带电次级的弹性总率缓存。水微束、显式电子开启的微束及 generic 未启用这些新缓存。

## 实现与物理范围

- `ct_sample` 可返回其实际命中的有向 CT 体素索引。缓存使用这个索引，不复用夹紧后的计分索引。34,749 个方向/边界/模体外位置检查保持原材料和密度一致。
- 实际材料和密度元组逐一计算，不用密度节点近似；复用现有 continuous26 数据和 GPU 上下文驻留缓存。RT07575 head 共3967个元组、638687个 FP32 射程节点（2554748bytes）。元组过多时继续原连续密度计算，不替换缺失物理数据。
- 质子解析逆算通常2次，碳3次；保留1e-6相对射程残差检查和原5次更新回退。目标射程模型不变，但有限精度、终止位置和后续事件计数并非逐位一致。
- 核弹性按原能量节点累加13个靶元素总率，再插值两个总节点。靶核选择、角分布、二体运动学、反冲阻止本领及共享核光学深度不变。FP32求和重排会造成极少数核事件计数差异。
- 主粒子患者内和铜中涨落ON，次级及铜碎片受限涨落OFF，碳铜 hard-delta 保留。患者强制0.5mm、铜0.05mm；源发射度、权重、几何、Urban、核模型和校准均保留。未推广 broadbeam 的 Giles/native 数学或密集尾部 Gamma 近似。
