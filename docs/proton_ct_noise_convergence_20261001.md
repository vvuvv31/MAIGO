**Proton CT minibeam：提高粒子数后的局部 3% / 0 mm（2026-10-01）**

GPU 与 TOPAS 均从 1000 万提高到 **5000 万入射质子**。通过率从 57.5466% 升至 **81.6437%**，增加 24.0970 个百分点。这验证了原始逐点超差中有显著蒙卡噪声。

5000 万时逐点剂量差标准误中位数仍为 **1.4706%**。因此 81.6437% 是本次更高统计量下的实测值，**不能称为已经排除蒙卡噪声后的极限通过率**。有限电子响应库的不确定度同样未被增加入射历史数消除。

“仅历史噪声对照”不是无噪声 GPU/TOPAS 通过率，也不是严格上界。各引擎的独立批次平衡拆成 A/B 两组（每组 N/2），构造 E=(GPU_A−GPU_B−TOPAS_A+TOPAS_B)/2。每个引擎的平均物理偏差在期望上抵消；当每历史方差稳定时，E 的方差与完整 N 粒子的 GPU−TOPAS 剂量差相同。对 E 应用相同的 3% 阈值，表中为 16 个可复现随机平衡拆分的通过率平均。拆分之间相关，其极差不是独立置信区间。不能用“实测通过率 + (100%−噪声对照通过率)”推算无噪声结果。

5000 万时评价点数为 124,769。对逐点剂量差构造未作多重比较校正的 95% Welch-t 区间，区间完全在 ±3% 内的点占 16.305%，完全在容差外占 1.080%，仍跨越容差边界占 82.615%。这些只用于展示逐点统计分辨能力，不是无噪声通过率的同时置信界。

标准误用独立批次估计。原数据为 20×0.5M，新数据为 20×2M；按历史数加权。对于各批次每历史剂量 D_i 和历史数 N_i，均值 D̄=ΣN_iD_i/ΣN_i，均值方差估计为 ΣN_i(D_i−D̄)²/[(K−1)ΣN_i]，假设方差随 1/N_i 缩放。两引擎独立，剂量比使用误差传播，逐点区间使用 Welch 自由度。这些估计仅包含历史采样噪声，未包含有限响应库的不确定度。
