# 关闭 δ 抽样的吞吐消融（2026-09-14）

只用于耗时诊断，不是精度合格的替代物理模型。正式源码与配置未修改；独立源码副本和两个诊断二进制位于 scratch/delta_disabled_20260914。诊断二进制拒绝 production 模式，并明确打印 invalid dose physics。

- baseline：完整统一 EM。
- no_draw：保留候选 δ 碰撞时钟与步长限制，跳过候选碰撞处的实际率接受、电子能量和形状因子抽样；δ 能量不扣除、不沉积。
- no_delta：进一步取消 δ 时钟/距离限制，保留受限连续能损、涨落、MCS、几何与原有核过程。
- 两种诊断均未把缺失 δ 能损补回连续 stopping，因此射程、路径和核历史改变。不能把吞吐差直接解释为某个函数的独占耗时或保证可实现的精度保持加速比。
- RT07575每轮1,000,000原发，b3每轮200,000；统一包和Schneider v2.1核数据不变，沿用既有完整spot分布与chunk设置。GPU仅本地，串行运行，各三轮。吞吐单位为原发 histories/s；不包括全部次级轨迹数。
