# 26组成：出生份额、硬碰撞率和条件终态

本轮已实现这三项的候选生成器和FP32查询/抽样接口。**候选尚未接入生产GPU worker；默认电子包仍为83节点。** 子组件实现完整不表示其近似通过剂量验收。

## 出生能量份额

`electron_response26::birth_fraction_from_em`直接接受现有连续26组成离子EM给出的受限能损期望和δ能损期望：`F = delta_mean / (restricted_mean + delta_mean)`。这些是同一能量、cut和路径上的期望，不使用单次已采样的δ能损作为分子。再用`partition`分割已经采样的离子总EM能损：电子包`W = total_loss * F`，局部沉积`total_loss - W`。不额外加入δ能量，不包含核反应沉积。

- `check_electron_birth_fraction26.cpp`以实际默认连续26离子包扫描26组成、proton/C12、16密度点和128能量点，106,496项通过；59,909项份额为零，分割能量相对残差最大5.92e-8。
- `check_electron_birth_fraction_native26.py`与已完成的高统计原生提取比较：proton160个母能量箱、carbon123个箱，均>=50MeV/u。份额最大绝对差为0.00303645/0.00147926，即0.303645/0.147926个百分点；中位绝对差为0.051202/0.018510个百分点。
- Carbon最大差达到38.02个聚类历史标准误，不能当作纯噪声或原生等价。比较还包括有限步长的pre-step分箱和连续slowing-bin积分差异。该份额差不能直接当作体素剂量差。

该份额API不读取83节点出生包。另一条用于对照的经验份额来自26组成条件分布的总权重；它仍由83节点的离线来源拟合，在部分组成出现大误差，未被选为默认。**EM期望份额与5MeV分箱CDF不能在未核对cut起点和硬事件母能量之前直接组合。** 原解析出生抽样的原生验证仍只覆盖>=50MeV/u。

## 硬碰撞率

`build_electron_response26.py`为每个组成/过程建立共同能量区间，保留区间内三次率表示。密度依赖为隐式log密度分区中的连续质量响应；模型目录只有26组成，没有原83节点注册表。当前字段`density_degree`表示分区数，不是能量多项式阶数。每次查询仅使用邻近两个控制值，再乘真实密度；终态控制选择按**事件实际能量的过程率**加权。

`check_electron_response26_rates.py`使用现有向外舍入区间认证器：52个过程模型、102,901个控制区间全部通过，上界证书最大比值0.158828；故意减半上界的负例被拒绝。这证明majorant覆盖候选定义的FP32率，**不证明候选率与原生物理响应一致**。

独立原包对照显示低密度section0/1的最大率误差仍约为对应过程峰值的5.24%/5.07%。原生阈值附近的相对误差更大，必须同时报告峰值归一化绝对误差。这部分未通过精度门槛，不能凭上界证书接入默认。

## 条件终态

Proton/carbon出生、共用charged和photon均生成26组成候选。记录按`pdg + energy + cosine`组成稀疏联合单元；保留全部正概率单元及分支，单元内保存同一条件下的能量和角度均值。CDF仍使用uint64阈值，FP32状态字段。有限单元会缩减单元内部的方差及高阶相关性，因此不是无损压缩。

出生控制选择按出生份额加权，charged选择按实际事件能量的过程率加权，photon使用几何参数权重。小概率显式与整数随机数比较，避免`1-small`舍入成1而删除稀有控制。400,000次C++抽样和20,000次分区坐标检查通过；能量分割相对残差5.07e-8，稀有控制的直接区间检查通过。没有改局部/非局部分支语义或把需要输运的电子改为局部沉积。

所有26组成的原包对照已完成：出生7,689项、charged17,006项、photon59,595项；未发现缺失分支。Charged零midpoint率的箱另行计数，不冒充完整的箱内支持验收。

- 18组成：sections2–14、20–22、24及Water_75eV，在原提取密度点的份额和条件一阶矩达到FP32数值一致。这不是全密度或剂量验收。
- 剩余8组成：0、1、15、16、17、18、19、23，需继续修正cut条件响应和密度近似。
- 最坏经验出生份额绝对误差：proton1.59896个百分点、carbon0.90665个百分点；最坏条件能量均值相对差proton15.74%、carbon9.62%。不能忽略这些结果或全部归因于旧包噪声。
- section15/17的部分原提取密度非常接近，但响应不同；已保存具体母能量箱和份额热点，须独立核查统计误差及cut/步内状态，不能为拟合旧样本而无限增加条件表。

## 体积和选择

完整v3候选四组件压缩磁盘合计1,485,847,225字节；解压数组3,433,983,616字节，均不含joint和标量。Joint原本只有25组成，本轮未修改。这里不是实际GPU加载量；候选的控制数组复制较多，设备常驻量也没有得到改善证明。没有新的GPU吞吐或剂量实验，不宣称提速。

v2全域Bernstein平滑方案已拒绝；v3分区表示改善了误差和查询成本，但仍未通过全部组件精度要求。出生EM份额API和率认证器可以继续使用；经验终态全包保持实验状态。下一步应在真实cut和硬事件母能量上建立条件模型，优先独立核查上述8组成，然后接入worker并检查能量、EM、完成、队列溢出和正式gamma：broadbeam local1%/1mm>99%，minibeam local3%/0.2mm>99%，搜索0.1×DTA。现有head minibeam绝对门槛未过的事实继续单独报告。
