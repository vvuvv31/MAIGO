# Proton CT minibeam 电子包剂量贡献（2026-10-02）

当前预解码版本、RTX 2080 Ti，4 个独立种子，每个 200 万入射粒子，共 800 万。全程 `CARBON_DOSE_FP32=ON`、`CARBON_DOSE_FP64=OFF`。电子包贡献 CT 内沉积能量的 **10.2914%**，但入口谷区平均剂量贡献达到 **43.18%**。将包能量全部恢复为局部沉积会明显破坏峰谷分布，不能满足约 1% 的额外剂量变化预算。

## 测量方法

在隔离源码/二进制中增加两张 FP32 原子计分图：电子包实际在 CT 内的沉积 `E_actual`，以及每个主粒子步分配给电子响应的能量 `E_local`。后者在 group32 reservoir 选择之前记录到该步原本的局部计分体素，涵盖全部源权重。总剂量图直接读取既有计分结果。物理轨迹、RNG、任务内容和电子包输运保持不变。

逐体素使用 CT 密度和体积把 MeV 转换为 Gy，再重建 `D_local = D_total - D_actual + D_local_source`。这是同一输运历史下的剂量反事实，不是另一次关闭电子输运的模拟，也不是已经验证的新物理模型。计分图为各批历史之和，未按入射粒子数归一。

这里的“电子包”仅指当前 material response 重新分配的主粒子循环电离损失，不等于全部电子物理或全部电磁能损。带电次级的电子能损仍保留现有局部处理。响应库有限样本、密度插值、未跟踪光子以及既有中子剂量缺项等模型限制不因本诊断得到验证。

## 能量与局部差异

## 完整性检查

- 四批研究模式质量/能量/队列检查通过；最大相对能量残差 3.415e-7，队列溢出为 0。`accepted` 不代表临床物理验证通过。
- 前两个种子与已有同种子、同 200 万历史的正式版本结果比较：全部离散输运/EM审计、电子任务数/步进数/重启数一致；总剂量相对 L1 ≤ 5.079e-8；全部非零体素最大局部相对差异 ≤ 9.154e-7，没有新增/丢失非零体素。后两批未另跑匹配正式基线。
- 四批电子源减实际沉积及能量汇的残差分别约 0.0679、0.0667、0.0683、0.0669 MeV。电子实际图相对整数定点账本差约 8.42–8.45 MeV，在每任务 1e-6 MeV 累计截断界约 16.87–16.93 MeV 内。
- `E_total - E_actual` 无负体素；MeV→Gy 与程序输出的最大差异/峰值 ≤ 4.405e-8。
- 生产源码、配置和二进制不作本轮物理修改；生产二进制 SHA256 仍为 `55147e40b75845d57e5f4e48974f46b5f74294b0fb275fc9bd70d99b98697efd`。

## 对优化的约束

本轮否决“全部电子包改为局部沉积”作为约 1% 预算下的加速方案，并记录到 failed.md；没有实现这一快速输运分支，也没有测得其吞吐收益。结果支持继续降低电子响应实现成本，同时保留横向扩散；不能单凭总能量占比或深度均值去掉包输运。选择性近似还需要材料、密度、异质界面与逐体素证据，本轮未批准任何深度切换规则。

此前当前版本的干净配对基准中，电子队列平均 9.0333 s，输运 25.9223 s，完整运行 47.9068 s（每批 200 万）。若仅将电子队列时间理想化降到零，其余耗时不变，Amdahl 上限约为输运 1.535×、完整运行 1.232×；这不是可实现或已测得的加速，其他批量/缓存条件也会改变比例。本轮带额外计分的时间不用于性能结论。
