# 低能 δ 批量抽样研究候选（2026-09-14）

本轮实现了冻结局部状态的复合泊松抽样，尚未通过剂量精度验收，也没有达到吞吐优化目标。默认编译选项 `CARBON_EM_DELTA_BATCH=OFF`，默认运行参数 `em_delta_batch_cut_scale=1`。生产模式拒绝启用批量抽样。此前完成的优化保留，本轮没有 commit/push。

## 实现边界

- 保留统一包的原 production cut Tc；研究分割阈值 Ts=scale×Tc。Tc 到 Ts 的软部分抽取 Poisson 碰撞数，每个事件仍使用原能谱的条件分布；Ts 以上硬碰撞仍显式抽样。
- 解析积分采用形状因子 veto 之前的 proposal spectrum，保留自旋和磁矩项，抽取能量后执行原 veto。因此不是把 proposal rate 当作全部接受事件率。
- 原 Tc 以下受限能损和涨落保持，软 δ 能量单独加入一次；不对软能损作高斯替代或均值替代。批量能量超过可用动能会拒绝该运行，不用裁剪掩盖问题。
- 仅在 E/A≥20 MeV/u、两密度节点 range≥5 mm、rho≥0.2 且 Tmax≥2Ts 时启用。最大宏观步为0.25 mm，同时限制预估能损约0.5%、全 proposal 数期望≤8；最终步长仍受几何和核碰撞限制。低能/阈值区域回退。
- 所有18种已支持带电离子共用该实现；未改核数据、未增加电子轨迹。
- 软部分在连续能损后的状态冻结，MCS随合并后的输运步更新，因此改变了有限步近似。这不是原逐碰撞算法的严格等价重构。

## 验证

- 原谱全区间采样与旧采样器逐位一致；软硬概率闭合及硬率比例上界检查约706,420次通过。
- 216组分布情景（所选水/Schneider密度节点、符合启用区间的离子/能量、Poisson均值0.1/4/8），每组30,000次；均值、二阶矩、零能损质量与独立数值积分一致。
- 主机及RTX 2080 Ti GPU均通过，最终使用与输运相同的Philox发生器。初版GPU测试用线性相邻种子直接初始化简易xorshift，统计检验失败；改用Philox后通过，未修改物理抽样公式或放宽阈值。该初版失败日志保留。
- 配置 guard 检查通过；输运试验 quality accepted，零overflow。这里不代表患者Gamma已验收。

4倍阈值降低了部分原发步数，但逐电子能谱采样仍保留，同时新增Poisson计数、谱积分、接受率计算和线程分支；本轮没有实现有效加速。8倍阈值使更多原发不满足Tmax≥2Ts，触发回退，不能理解为所有原发都采用更激进合并。

批量抽样改变随机数消耗和输运步，不再要求事件计数或单体素剂量逐位相同。b3初版4倍阈值的IDD最大差异约参考峰值的0.188%，积分变化约0.026%；这只是与旧GPU的低统计筛选比较，不能宣称TOPAS精度改善或通过严格门槛。CT的20万原发单体素差异非常嘈杂，未计算BODY Gamma，也不把该差异报告成Gamma误差。

## 后续方向

逐个抽取低能电子的Poisson批处理不推广。真正减少工作量需要直接抽取低能段总损失分布，例如对复合泊松分布离线求解并构造分位数表，运行时按材料/离子/能量及局部碰撞强度插值，保留零事件质量、均值、方差和高尾。该方案尚未实现，新增表须绑定原统一包及生成方法的校验信息。

先验证总损失分布与步长依赖，再测100/200/300 MeV/u、b3/b4及RT07575；达到吞吐收益后才值得扩大统计并做TOPAS剂量验收。患者Gamma采用RTSTRUCT BODY和DTA/10搜索步长。不得用均值替代涨落、调TOPAS或放宽验收来制造收益。
