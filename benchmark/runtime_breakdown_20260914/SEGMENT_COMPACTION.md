# 次级分段续跑：块长与压紧成本评估

结论：值得做64步分段续跑原型。现有证据支持压紧/状态搬运成本较小，但尚未测量任何完整输运提速，也未接入生产。

## 用真实轨迹长度重建分段队列

使用上一轮RT07575的4,068,710条次级轨迹及实际线程顺序，保持真实两个代际kernel批次边界。每轮对所有活跃轨迹最多推进B个EM调用，再稳定压紧剩余轨迹；队列小于8192时直接跑完。这里没有改变物理步长，是离线工作调度模型。

|块长B|有效EM步槽位代理指标|输运启动数|压紧边界数|续跑状态次数|小队列尾部EM工作占比|
|---|---:|---:|---:|---:|---:|
|32|87.62%|77|75|19,319,188|0.952%|
|64|79.43%|40|38|9,056,351|0.916%|
|128|66.21%|22|20|4,032,483|0.789%|

原始次级指标为23.67%。该指标只假设每个EM调用等成本，不是硬件occupancy、墙钟效率或预期加速。32步改善代理指标最多，但状态搬运约为64步的两倍；128步启动/搬运更少，但保留更多块内长短轨迹差异。64步是用于第一个原型的折中，不是已优化出的生产默认值。

## 本地GPU实测稳定压紧成本

使用同一真实轨迹长度驱动的队列变化和128/256/512字节模拟状态。每次压紧由三个kernel实现：group扫描存活标志、block计数前缀和、按稳定目标下标搬运状态；每轮读回存活数。block=256，RTX2080Ti。每组运行3次，表内为墙钟中位数，包含这些kernel及同步/存活数读回。

|状态大小|32步|64步|128步|
|---|---:|---:|---:|
|128字节|0.188s|0.075s|0.022s|
|256字节|0.476s|0.193s|0.051s|
|512字节|1.036s|0.425s|0.122s|

这是整个1M患者运行所对应次级队列序列的压紧成本，不是每轮成本。退出时逐条校验剩余寿命、原始ID和所有模拟状态字段，确保稳定顺序且未丢失/损坏状态。

该微基准不执行几何、能损、核过程、MCS或剂量记分，不包含实际输运kernel暂停时写出和恢复时读入状态的全部成本，也不包含轨迹状态加载后的寄存器影响。模拟状态搬运与真实物理读写的缓存竞争没有测量。不能简单将约0.19秒加到某个理想化输运时间上预测最终吞吐。输入/分配/初始化和退出验证不计入表中墙钟；生产采用GPU驻留状态，不能逐轮走CPU状态读回。

## 状态体积初步审计

`resume_state_size.cpp` 中的候选核心状态为120字节，附带现有UnifiedEmState材料缓存后216字节。核心包括原始fragment索引、累计step数、位置方向/能量、pending剂量bin及累加、δ时钟、EM RNG计数器、rate/step诊断累计、连续能损tally与终止标志。

这是字段草案而非完成的续跑结构：He4诊断、local EM audit、profile等可选状态还需单独支持，不能把216字节当作全部运行模式的最终大小。原始fragment、parent history、generation、rng_stream等可通过稳定索引引用；该原始存储必须保持有效。不得按32M次级容量无条件分配两份大状态池，应按实际代际队列/可用显存分配并保留溢出拒绝。

## 64步原型的具体约束

1. 在独立源码中抽出次级轨迹初始化、分段推进、正常终止三个阶段。保持种类分组后的原始顺序，压紧稳定；第一次原型保留原生EM与全部当前物理路径。
2. 在完整EM迭代结束点暂停，记录真正的暂停原因。达到64步是“未完成”，不能进入当前while之后的terminal-deposit、escape、停止计数与birth累计逻辑。正常核反应终止、低能、逃逸、失败仍执行原逻辑。
3. 原生RNG流、累计sec_steps、δ剩余光学深度/阈值/缓存、未提交的dose累加必须恢复；pending剂量不能因调度边界提前flush来改变有限精度累加顺序。每轨迹初始化和终止诊断只记一次。物理时间步不得合并。
4. 同一代的未结束轨迹先续跑完，再按既有代际语义处理新生次级，保持生成上限与能量记账。小于8192轨迹时用同一状态继续跑到正常终止，不重复初始化。8192只是本次候选阈值，需端到端A/B再决定。
5. 验证暂停恢复前后逐轨迹能量、RNG和时钟；随后同粒子数CT A/B，检查EM audit、核反应计数、停止/逃逸记账和零overflow。若剂量差超过累加顺序噪声，必须定位。含独立核弹性的情景需要另外覆盖，不能从当前无弹性基线继承验收。
6. 输出原发/次级推进、压紧、状态读写与总吞吐，拒绝以采样代理指标或sampler微基准替代完整加速结果。未达收益门槛不接入生产。

本轮完成到可行性评估与压紧微基准，完整物理续跑原型尚未实现；没有承诺50k/s。正式代码和配置未修改，未commit/push。
