# RT07575 full minibeam plan, group32

Reference: sibling RT07575_minibeam/code/output_minibeam/physical_dose.mhd (4 Gy per fraction; NOT the 16-fraction export). The reference is 870 TOPAS DIJ columns, each from 1,000,000 incident protons; 487 have nonzero optimized weight. The optimizer reports nonconvergence; this benchmark uses the supplied weights unchanged.

Incident protons for 4 Gy: 236086432317.40375. Requested GPU histories: 23608643 (0.01%, aggregate rounded; user reduced the request before transport). Largest-remainder per-spot allocation, balanced across 12 shards, each <=2M. FP32 GPU scoring, group32 electron replay. Offline summation uses float64 without changing GPU scoring.

Geometry: TOPAS patient passive RotZ=90 degrees, translation (-42.8515,-12.7636,1.3617) mm. Canonical GPU=(world X, world Z, world Y+117.0136). CT densities and section IDs checked voxelwise against original DICOM. Packed CT order is [patient X descending, patient Z, patient Y]; origins shift by patient world X/Z, without resampling. Copper center z=-50 mm, thickness60 mm; exit20 mm upstream of CT.

The opt-in `spots_geometry_mode: minibeam_pbs_y` preserves the PBS source plane at world Y=-450 mm and samples tan(theta_scan+angular_emittance), matching the original TOPAS PBS extension. Legacy rotated-frame emittance is unchanged. Original extension sources are frozen under inputs/topas_extension. Gaussian optical parameters are interpolated from the original table; no retuning. The minibeam Cu and air transport remains explicit.

`prepare.py` freezes inputs and resolves integer allocations. `run_gpu.py --pilot 100k` / `--pilot 2m` run preflights. `run_gpu.py` runs resumable groups of4 shards, checks quality/energy/overflow reports, saves accepted records, and aggregates dose. The frozen binary identity is in build.json. `compare.py` computes 3D local/global gamma on BODY union GTV above10% of the whole-reference maximum; finite spherical lattice step=DTA/10, trilinear evaluation, no fitted normalization or registration. Dose spacing is0.5x0.5x2 mm; subvoxel gamma uses interpolation and is not evidence of0.2 mm physical resolution.

Dose is scaled only by optimized incident protons / actually simulated histories. Partial results are explicitly marked partial; partial shard weights can have small integer-allocation imbalance. Inspect campaign_status.json, results/summary.json, results/gamma_cutoff10pct/gamma.json and plots. Every rejected shard halts the campaign. The reference includes full TOPAS secondary/neutron physics; current GPU CT neutron transport remains disabled and group32 material-electron replay is a research approximation. More primary histories reduce sampling noise but cannot establish physical equivalence.

RT07575 bank extension: the lung bank failed preflight before transport because sections15–19 lacked endpoint densities and sections20–24 were absent. `extend_bank.py` generated19 homogeneous tables using the original TOPAS response binary,16 proton histories per table at250 MeV, same EM/Urban/cut settings and compiler. Density knots include exact CT extrema and keep adjacent ratios<=1.2. Original bank entries are unchanged. Full source histories and energy audits are under response_extension; this extends coverage, not a claim of converged electron response accuracy.
