# RT06423：head CT GPU/TOPAS 蒙卡结果

更新：2026-08-04。该病例的严格 full-plan GPU/TOPAS 比较有效，结果来自完全
一致的正权重 spot integer allocation；详细统一口径见 [ctResult.md](../ctResult.md)
和 [ctplan.md](../ctplan.md)。

## 计划与几何

- 解剖：head
- TPS 机架角：90°
- GPU 几何：`tps_90`，patient-X 为深度轴
- 输入 spot：1102；正权重 active spots：1015
- Dij 每 spot：50,000 histories
- 严格 full-plan histories：15,108,664
- TOPAS：4.2.p3 / Geant4 11.3.2，56 tasks，K=100 仅表示每个 history 的剂量权重，实际独立 histories 仍为 15,108,664

比较区域为 RTSTRUCT BODY 与 TOPAS 剂量达到 BODY Dmax 10% 的交集；剂量和 LET
都不在比较前做拟合归一化。LET gamma 使用 dose mask，不使用 LET 自身阈值。

条件化末态和 LET scorer 定义有关，不能只用主碳射程解释。
