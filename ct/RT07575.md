# RT07575：head CT GPU/TOPAS 蒙卡结果

更新：2026-08-04。该病例同时包含普通 CT full-plan、1B fast/best profile 收敛
和 minibeam 验证。统一比较口径见 [ctResult.md](../ctResult.md)；几何定义见
[ctplan.md](../ctplan.md)。

## 计划与几何

- 解剖：head
- TPS 机架角：90°
- GPU 几何：`tps_90`，patient-X 为深度轴
- 输入 spot：917；正权重 active spots：853
- Dij 每 spot：50,000 histories
- TOPAS 严格 full-plan histories：12,963,817
- TOPAS：4.2.p3 / Geant4 11.3.2，56 tasks，K=100 不增加独立统计样本

所有结果使用 RTSTRUCT BODY ∩ TOPAS dose ≥ 10% BODY Dmax。LET gamma 采用 dose
mask，不采用 LET 自身阈值；3D gamma 使用 0.5 mm 三线性搜索，3%/0 mm 使用全部
选择体素。

## 1B fast/best profile 与 TOPAS

GPU 每个 aggregate 为 100 个 10M-history batch 的等权平均；dose 使用
`12,963,817 / 10,000,000 = 1.2963817` 放到 TOPAS 整数计划尺度，LET_d 是比值，
不乘该因子。没有拟合 scale。

### 运行时间

| Profile | histories | wall time | wall throughput | LET scorer |
|---|---:|---:|---:|---|
| fast seed A | 1B | 4256 s（1.18 h） | 234.96k/s | off |
| fast seed B | 1B | 4240 s（1.18 h） | 235.82k/s | off |
| best seed B | 1B | 21346 s（5.93 h） | 46.85k/s | on |

所有 batch 的 secondary/cascade queue overflow 均为 0。

### best seed B 与 TOPAS

| Quantity | 3%/3mm G/L | 2%/2mm G/L | 1%/1mm G/L | 3%/0mm G/L |
|---|---:|---:|---:|---:|
| Dose | 99.978 / 99.802% | 99.728 / 97.852% | 90.320 / 64.774% | 80.451 / 45.219% |
| Primary C-12 LET | 99.916 / 99.500% | 99.574 / 98.010% | 96.140 / 87.580% | 97.532 / 77.960% |
| All-hadron LET | 99.762 / 98.300% | 99.078 / 94.506% | 93.482 / 74.824% | 94.844 / 71.738% |

Best dose 的 GPU/TOPAS integral 为 0.999947，dose NRMSE/Dmax 为 2.327%；因此
整体 scale 已基本正确，1%/1mm 和 3%/0mm 的剩余差距主要是 voxel-level 统计、
低剂量 local criterion、source/物理模型和 scorer 差异的共同结果。TOPAS 的
12.96M 独立 histories 相比 GPU 1B 少约 77 倍，确实会使 TOPAS 统计噪声约高
`sqrt(77) ≈ 8.8` 倍，但增加 TOPAS 粒子数不能单独消除系统误差。

### best seed B 与 fast seed B 的 GPU-GPU 诊断

该诊断使用相同 BODY/TOPAS dose mask，fast seed B 为 reference；它衡量 profile
物理链差异，不是 TOPAS 误差：

| Quantity | 3%/3mm G/L | 2%/2mm G/L | 1%/1mm G/L | 3%/0mm G/L |
|---|---:|---:|---:|---:|
| Dose | 100.000 / 61.486% | 99.996 / 40.404% | 99.814 / 13.734% | 99.997 / 13.298% |
| Primary C-12 LET | 99.994 / 92.670% | 99.914 / 88.118% | 98.790 / 81.636% | 98.928 / 80.745% |
| All-hadron LET | 99.096 / 69.804% | 92.906 / 51.274% | 85.164 / 11.080% | 94.546 / 5.450% |

这说明 local gamma 对低剂量区和 profile 物理近似极其敏感，即使两个 GPU 结果
都使用 1B histories，local 3%/0mm 仍可能很低。

## LET_d 统计解释

Primary C-12 LET 的均值和空间分布较稳定；all-hadron LET 由稀有碎片事件贡献，
因此对 TOPAS 独立 histories、fragment cascade 和 scorer cutoffs 更敏感。若要
区分 TOPAS 统计噪声和系统误差，应比较两个独立 TOPAS seed，或将 TOPAS K=100
提高到 K=10（129,638,173 独立 histories）后重复同一 gamma。

| Gamma 条件 | Global | Local |
|---|---:|---:|

Dij threshold audit 与 seed convergence 见 `out/ct/RT07575/minibeam_plan/VALIDATION.md`。
