## 原因排序与证据强度

1. **已确认的评估误差：Gamma 搜索太粗。** 在不变剂量上重算即可复现，是此前 local11 低通过率的主要原因。
2. **最值得优先验证的输运原因：入射端电子空间能量分配/非平衡。** 当前实际启用 section0 横向 delta-tail；包只重分配横向位置，不输运纵向电子轨迹。其 metadata 指明从均匀 HU=-1000 材料的深度100–200mm区间提取横向统计，而当前失败在入口0–12mm，不能认为提取条件已覆盖入射建立区。核算代码不会沿入射空气段逐步生成并携带电子进入后续体素；这与入口空气的 GPU 连片偏高相符。这里只是有机制支持的优先假设，尚未通过电子开关/匹配物理对照确定因果或贡献百分比。提取材料是 HU=-1000，不能误用原发 stopping 表 HU=-975 的参考密度来论证。
3. **不能由统计噪声单独解释。** 5个TOPAS重复及20个GPU近等源分片估算：local33失败区实际偏差RMS约6.92%，合并统计噪声RMS约0.44%；全掩膜实际RMS1.93%，噪声RMS0.78%。方差估计有有限重复样本不确定性，不能视为逐体素精确置信界。
4. **缺失独立核弹性可能贡献，但目前不是已证实的主因。** GPU该过程关闭，TOPAS参考包含hadronic elastic。它可改变带电粒子偏转、横向/远端尾部和反冲剂量；Highland MCS不包含这部分核反冲。入口低密度空气的局部物质量较小，且大部分残差在这里，不支持仅据总Gamma就把它全部归因于核弹性。上游散射或组织反散射仍可能影响入口，不能排除。定量需要同一TOPAS设置下核弹性ON/OFF的过程匹配对照，或实现验证后的GPU elastic后对照；本次未运行这类模拟。
5. **整体归一化/刚体位移不是充分解释。** 一阶偏移+比例诊断仅解释约5.9%的局部误差方差；没有对实际Gamma施加拟合、移位或重归一化。不能因此排除更局部的几何/源/评分差异。

TOPAS五次重复的binheader记录未记分能量合计约0.19048MeV；这是很小的总能量，不能仅看到大量“未记分步数”就认定其解释了这些连片偏差。
